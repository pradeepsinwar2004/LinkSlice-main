# 🔗 Intelligent URL Shortener

An efficient and intelligent URL shortener that reduces long URLs by up to **80%**, enabling quick sharing and seamless redirection. Designed with scalability and performance in mind, it handles 200+ URLs with fast response times and persistent storage.

---

## 🚀 Features

- 📉 **URL Compression:** Shortens long URLs by up to 80%
- 🚀 **Fast Redirection:** Efficiently redirects users to original URLs
- 🔄 **RESTful API:** Full CRUD support for custom integrations
- 🗃️ **Scalable Storage:** Stores and manages over 200+ URLs
- 🛡️ **Validation & Error Handling:** Ensures reliable and secure URL management

---

## 🛠️ Tech Stack

- **Backend:** Node.js, Express.js
- **Database:** MongoDB
- **API Type:** RESTful API
- **Other Tools:** Postman (for testing), MongoDB Compass (for DB visualization)
